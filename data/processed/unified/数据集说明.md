## 使用哪些文件

- `unified_electrolytes.xlsx`：便于查看的工作簿，包括主表、清洗子集、RT候选、跨源对应、结构、bulk/total辅助标签、组成索引和字典。
- `measurement_records.csv`：**3,335条**主表，59个字段，保留每条来源记录、原值、来源位置、原始字段JSON和SHA256。
- `clean_numeric_records.csv`：**1,878条**；组成可解析、正数精确标签、无当前质量标记、来自公开原表。保留不同温度；不包含未核实 Laskowski 转录。
- `reported_rt_candidates.csv`：**1,393条**；上述条件+来源声称室温/明确15–35°C，并排除已标明高温外推者。其中464条有明确数值温度，其余仅有来源室温声明。bulk/total、是否直接测量等仍可能未知，不能当作已完全同质化的训练集。
- `censored_records.csv`：**89条**界限记录，主标签log值为空；其中52条来自未核实转录。
- `review_queue.csv`：所有有质量标记的记录；原始记录仍保留，不悄悄删除。
- `structures/`、`structure_manifest.csv`：**321个实际CIF文件**及每个文件的哈希、对应来源记录和结构匹配状态。ICSD标识本身不会变成未下载的CIF。公开CIF含坐标扰动，不能当作全部为原始实验坐标；本快照按上游脚本和ICSD字段推断289条触发扰动条件、32条不触发，与论文291/30的描述不完全一致，尚未逐个核实，不强改计数。
- `obelix_auxiliary_bulk_total.csv`：57个原表额外bulk/total字段值，单独保留并关联父记录；未混入3335条主表计数。
- `cross_source_links.csv`：**1,519对**相同归一化组成+至少一个相同DOI的跨库候选对应；不是已证实的重复样品。
- `cross_source_conflicts.csv`：条件/相信息冲突或电导率相差超过1dex的候选对应。该结果含未核实转录，不是新物理发现。
- `composition_index.csv`：**1,193个**解析组成组；同组成可有不同温度、相、加工和样品，不等于独立材料数。
- `data_dictionary.csv`、`cleaning_log.csv`、`source_manifest.json`、`liion_version_differences.csv`：字段释义、逐条清洗操作、来源/许可/哈希和官网修订差异。

## 清洗与重叠规则

1. 原始文件只读保留，规范化字段与原值分开。此次四个表的电导率原单位均为S/cm；逐条保留单位和比较关系。
2. 仅精确正数电导率生成log10标签。89条删失界限不作精确回归值，不用界限填补真实电导率。
3. LiIon明确标为摄氏度，转换为K时加273.15。其余来源仅写室温时不擅自填298.15K。McHaffie的最低外推温度单列保存，135条高温最低测量记录均不能进入RT候选子集；`na`不推断为直接测量。
4. 化学式只处理可解释的Unicode、成对外层引号和空白。括号与小数计量按原文计算；名义配方不保证单一晶相。混合物/添加量、错位下标、未知元素、不平衡括号等标为待核验。**485条**主记录存在化学式解析问题，仍保留在主表。
5. LiIon采用[官网完整表](https://pcwww.liverpool.ac.uk/~msd30/lmds/LiIonDatabase.html)，包括2024-10-18公布的703号修订：`Li6NiBr3 → Li6NBr3`、`1.50e-7 → 3.10e-7 S/cm`、DOI改为`10.1002/anie.198000741`。官网还修正了旧转录后段重复ID引起的编号错位。388号DOI字符串亦有差异，原样记录，不猜测哪种写法正确。
6. 不按化学式或DOI粗暴去重，不强行平均不同温度、bulk/total、相或未知样品条件。当前**确认同一样品后删除的重复记录为0条**。跨库匹配按数值、温度、空间群和测量类型区分证据层级；同值仍可能来自不同样品。
7. Sn–S–Se个别标签对应仍需最终发表版本核验，仅添加疑点标记，不自动交换数值。
8. 提供共享组成或任一DOI的传递连通分组`leakage_group_id`（353组）。后续模型划分应使用分组，不能把来源重叠当作外部独立测试；不直接沿用OBELiX旧划分。该分组不是去重结果。

在包内项目根目录运行：

```bash
python3 -m pip install numpy pandas lxml openpyxl
python3 run_unified_dataset.py
python3 -m unittest discover -s tests -p test_unified_dataset.py -v
```

已经下载的原始文件足以离线重建本版，不需要访问DDSE、ICSD或付费API。浏览器检查脚本是可选的；它使用独立临时Chrome会话，不读取个人浏览器配置。项目内依赖可安装于`experiments/vendor`，数据脚本也可使用标准Python环境中的包。

本版可用于来源审计、待核验队列和带条件筛选的探索分析。五库全量仍有上述两个明确缺口；本版不声称完成逐条原文复核，也不声称取得重大科学发现。
